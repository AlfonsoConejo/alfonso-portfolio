A comprehensive academic planning platform designed to help students organize their university life.

**Key Features:**
- JWT authentication with HTTP-only cookies and a refresh token system stored in PostgreSQL.
- Academic period management, displaying only the information for the user's selected period.
- Subject and class schedule management with customizable color labels.
